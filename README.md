# Lic-Sistemas | UNLP

Repositorio personal con material, prácticas y proyectos desarrollados durante la cursada de **Licenciatura en Sistemas** en la **Universidad Nacional de La Plata (UNLP)**.

## Contenido del repositorio

### Materias

* **Algoritmos y Estructuras de Datos (AyED)**
* **Fundamentos de Organización de Datos (FOD)**
* **Seminario de Python**
* **Orientacion a Objetos 1**
* **Ingenieria en Software 1**
* Otras materias y trabajos prácticos de la carrera

## Organización

El repositorio se encuentra organizado por:

* **Año**
* **Cuatrimestre**
* **Materia**
* **Trabajo Práctico / Ejercicio**

```text

```
